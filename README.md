# Industrial Management System

## Overview

Industrial Management System is a Laravel-based web application developed to manage customer orders, delivery records, and industrial workflow operations efficiently.

## Features

* Customer Management
* Delivery Management
* CRUD Operations
* MVC Architecture
* Database Integration with MySQL
* Form Validation
* Responsive User Interface

## Technologies Used

* PHP
* Laravel
* MySQL
* HTML
* CSS
* JavaScript
* Blade Templates

## Project Structure

* Controllers for business logic
* Models for database interaction
* Blade templates for UI
* Routes for request handling
* Migrations for database schema management

## Installation

1. Clone the repository

```bash
git clone <repository-url>
```

2. Install dependencies

```bash
composer install
```

3. Create environment file

```bash
cp .env.example .env
```

4. Generate application key

```bash
php artisan key:generate
```

5. Configure database in .env

6. Run migrations

```bash
php artisan migrate
```

7. Start server

```bash
php artisan serve
```
